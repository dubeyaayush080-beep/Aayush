## 🚀 Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, Edge)
- A code editor (VS Code, Sublime Text, etc.)

### Installation

1. Clone the repository:
```bash
git clone https://github.com/dubeyaayush080-beep/spidey.git
cd spidey
```

2. Open `index.html` in your browser:
```bash
# Using Python 3
python -m http.server 8000

# Or simply double-click index.html
```

## 📝 Customization

To customize the portfolio for your own use:

1. Update `index.html` with your information:
   - Change your name, title, and bio
   - Update skills and proficiency levels
   - Add your own projects
   - Update contact information

2. Modify `style.css` for custom colors:
   ```css
   --primary-color: #ff0055;     /* Change primary color */
   --secondary-color: #00d4ff;   /* Change secondary color */
   ```

3. Update social media links in the contact section
